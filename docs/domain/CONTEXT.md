# 排课领域

本上下文定义线下教育排课过程中用于描述时间安排与资源可用性的统一业务语言，避免沿用旧表中的歧义标签。

## Language

**排课项**：
会影响老师、学生、教室或校区时间安排的一项有起止时间的业务事项。

**授课安排**：
老师为一名或多名学生授课的一次具体排课项。
_避免使用_：课程（当它被同时用来表示课程产品、周期计划或单次上课时）

**可排时段**：
老师或其他资源明确允许安排授课的时间范围。
_避免使用_：空出

**禁排时段**：
老师或其他资源明确不能安排授课的时间范围。
_避免使用_：空出、占用

**取消授课**：
一项原定的授课安排确定不再发生，但其原记录和变更历史继续保留。
_避免使用_：删除课程、临时取消（当它实际表示费用比例时）

**费用参考值**：
从旧系统保留、仅供查看且不由本系统计算或判定的课程金额信息。
_避免使用_：应收金额、结算金额

## Relationships

- 一个**排课项**可以是一个**授课安排**，也可以是影响可用性的非教学事项
- **可排时段**与**禁排时段**含义相反，迁移时不得互相推断
- 一个老师可以拥有多个**可排时段**和多个**禁排时段**
- **取消授课**不会删除对应的**授课安排**
- **费用参考值**不决定一项**授课安排**能否创建、修改或取消

## Example dialogue

> **开发者：** “旧表这条‘空出’应该导入成可排时段吗？”
> **领域专家：** “不能直接判断；先确认它表示老师开放时间还是不能上课，再分别记为可排时段或禁排时段。”

## Flagged ambiguities

- 旧表中的“空出”同时表示不同业务含义；已决定废弃该词，迁移时逐条或按明确规则拆分为**可排时段**或**禁排时段**。
- “课程”可能表示课程产品、周期计划或一次具体授课；需要继续拆分并确定正式术语。
- 旧表“临时取消”同时暗示取消动作和扣费比例；已将业务动作统一称为**取消授课**，扣费比例仅作为**费用参考值**保留。
